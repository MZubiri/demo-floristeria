Datos de demostración

Guardados únicamente en este navegador.

No introduzcas datos personales, comprobantes o fotos reales de clientes. No hay servidor, sincronización ni respaldo automático.

La exportación no incluye fotografías. Borrar los datos del sitio puede eliminar la demo.

Volver a empezar

Restablece los pedidos de ejemplo y elimina los cambios y fotos locales.

En tu iPhone

  1. Abre la dirección web de la demo en Safari.
  2. Para un acceso directo, usa Compartir → Añadir a pantalla de inicio.
  3. Abre un pedido y entra en Fotografías para usar cámara o galería.
  4. Deja abierta la página mientras se procesa la foto.

El acceso directo no convierte esta demo en una app offline. La carga inicial requiere conexión. No requiere App Store ni una cuenta Apple Developer.

LA SIGUIENTE ETAPA

Preparada para crecer contigo.

En producción: API ASP.NET Core, MySQL, acceso privado por usuario, fotografías protegidas, conversión HEIC en servidor y respaldos externos.

En esta demo, las devoluciones y ajustes después de consumir materiales requieren desarrollo adicional. No se fingen cobros, autenticación ni sincronización.
